  (1) Have a README.md which shows how to setup the project and the project environment

  (3) Sequence Classification (WNLI)

            in bert_wnli_finetune_corrected.ipynb - but feel free to ask questions and if you find mistakes,
            feel free to correct them.

      (3.2) Zero-shot
            BERT/DistilBERT - is it the same dataset as the one for fine-tuning? If you have time, you can use the same, if not - it is fine.
            Upload your datasets, especially if they are less than 50MB to GitHub, and if possible use the same dataset
            for fine-tuning/zero-shot evaluation.


  (4) Token Classification (CoNLL2003)
      NER_finetuned_CoNLLTestSet.py - make sure to decode the predictions to the IOB format, as the dataset seems to follow it.
      NER_finetuned_RealTestSet.py - are these two different scripts? It is good to also include the source of the original source of the data (uploading the files is enough)

Overall, there are many nice things but also things one should be careful about. If you are interested and have enough time, it will be nice to consider the proposed changes.
